# Upstream

Four papers that carry no result on this list but hold up the ones that do. Each opens with a review note that takes precedence over its text.

**The 13 Primitives** — the canonical statement of the thirteen primitives. Where another paper cites a primitive loosely, this one wins. The primitives are stated in prose. They do not define a model anything can be calculated from, and the paper itself says P12's Σ cannot be evaluated as written.

**V1 Kernel_Finite Width Retarded** — a chain's response to its own earlier state. Its *shape* is a postulate, which is why it sits on [Foundation.md](../../Foundation.md) as axiom 21. Its retardation and finite width are argued informally; the paper labels those arguments theorems. Four results use it.

**V5 Kernel_Cross Chain Correlation** — the link between different chains. That it exists at all is axiom 14, and nothing derives it. Its envelope and memory time are free in each regime. Four results use it.

**GR-I_Weak Field Einstein Metric** — the emergent weak-field metric and the lapse, which the six gravity-chain results all pass through.

- **What it gets right:** the factor of two in light bending (PPN γ = 1), correctly, at first order.
- **What it does not fix:** the second-order metric. Read in the isotropic form it uses, it gives PPN β = 0, which observation excludes. The Schwarzschild form used downstream is reached by switching coordinate form, not derived.

A reader checking how exposed the gravity block is should start here.

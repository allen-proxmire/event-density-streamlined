# Upstream

Four papers that carry no result on this list but hold up the ones that do. Without them a reader following a result page hits a dead end.

**The 13 Primitives** — the canonical statement of the thirteen primitives. Every result uses some of these, and this is the paper that fixes what each one says. Where another paper cites a primitive loosely, this one wins.

**V1 Kernel_Finite Width Retarded** — a chain's response to its own earlier state. Its *shape* is a postulate, which is why it sits on [Foundation.md](../../Foundation.md) as axiom 21. Its retardation and its finite width are theorems here, resting on two of the four arguments. Four results use it.

**V5 Kernel_Cross Chain Correlation** — the link between different chains. That it exists at all is axiom 14, and nothing derives it. Four results use it.

**GR-I_Weak Field Einstein Metric** — the emergent weak-field metric, and the lapse. This is the paper the six gravity-chain results all pass through, and the band-accounting premise that gates them lives here and in GR-III §4. A reader checking how exposed the gravity block is should start here.
